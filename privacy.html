Privacy

Last updated: August 2026

The short version: your files stay on your device. Here's the exact breakdown of what happens when you use a tool on this site.

Your PDF is uploaded to a serverNo
Your PDF's content is stored anywhereNo
An account or sign-up is requiredNo
File names are loggedNo
The site loads code from third-party CDNsYes
Cloudflare (our host) sees standard request logsYes

How a file is processed

When you choose or drop a PDF, it's read into your browser's memory using the File API — the same mechanism any website uses to let you attach a file. The actual merge, split, or rotate operation runs inside your browser using JavaScript libraries. The output file is generated locally and handed to you as a download. Your file's content never becomes a network request.

What does leave your device

Two things, neither of which is your file:

  • The page itself. Loading VeloraPDF means your browser requests the HTML, CSS, and JavaScript from Cloudflare's servers, and editing libraries from a public code CDN. This is just code, not your data — the same way loading any website downloads the site's own script files.
  • Standard hosting logs. Cloudflare, who hosts this site, sees the same request metadata (IP address, browser type, page requested) that any web host sees for any site. We don't add analytics or tracking scripts on top of that.

Cookies

VeloraPDF doesn't set any cookies of its own. There's no login, so there's nothing to remember about you between visits.

Questions

If anything here is unclear, or you've found a case where a tool behaves differently than described, reach out via the contact page.
